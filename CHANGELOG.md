# Changelog

## 1.2.0 — 2026-10-24

First public GitHub release.

- Native battery indicator with the remaining percentage inside the icon.
- Green, orange and red charge fill with persistent custom thresholds.
- 5-hour, weekly or lower-remaining display; reset times and manual refresh.
- Configurable polling, launch at login, and clear unavailable / stale states.
- English, Simplified Chinese and Japanese interface and README.
- Universal Apple Silicon / Intel build targeting macOS 13+, deterministic checks, CI and SHA-256 checksums.

The app is ad-hoc signed and not Apple-notarized. Codex CLI and a ChatGPT-backed account are required.

## Local prototypes

Versions 1.0.0–1.1.1 were local iterations that established the quota reader, custom thresholds and colored charge fill. They were not public GitHub releases.
