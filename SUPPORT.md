# Support

Use [GitHub Issues](https://github.com/AdvancingTitans/codex-battery/issues/new/choose) for reproducible bugs or focused suggestions. English, 中文 and 日本語 are welcome. Response times are not guaranteed.

Before reporting:

- Confirm `codex login status` reports a ChatGPT-backed sign-in and `codex --version` works.
- Check that the CLI and desktop Codex app use the same account.
- For `?`, check the error and last-update time in the menu, then choose Refresh now.
- For `—`, choose another quota window; not every account returns both windows.
- Check macOS menu bar overflow if the icon is not visible. You can move menu bar items with Command-drag.
- This release is not notarized; building from source is an alternative if macOS blocks a download.

Include app / macOS / CLI versions and steps to reproduce. Redact account identifiers and private file paths. Never attach `auth.json`, tokens, cookies or an entire Codex configuration directory.

To uninstall, first turn off Launch at login in the app, quit it, then move the application to Trash. Preferences remain in UserDefaults unless you remove them yourself.
